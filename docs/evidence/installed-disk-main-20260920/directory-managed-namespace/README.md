# Managed child namespace primitive — target only

Status: **unapplied, scoped native PASS; caller migration and whole release qualification remain open**. Work was confined to `/Users/mtakemiya/dev/kasumi`, branch `master`. The frozen 49-file census dependency was not changed. `manifest.json` binds a nine-file successor and a 51-file cumulative patch; each applies to its exact saved baseline and reproduces the proposed bytes. No actual checkout source was changed by this package.

The public child capability has `open_child(&CStr)`, `create_child(&CStr, DiskWork)` and consuming `remove_if_empty()`. It accepts one bounded normal component, checks root-inclusive depth, retains exact ancestry and parent identities, rejects existing identity replacement, and refuses root removal or removal with aliases, separate owners, descendants or recorded children. Mandatory F/D/H/work-step and byte policies remain unchanged. There is no compatibility alias for the private `FileParent` type, now directly replaced by `RetainedParent`.

A single `PendingDirectory` is owned inline by State from before the first managed operation descriptor acquisition. New acquisitions preallocate bounded names, ancestry and the concrete private owner Arc, then count the owner slot before dup/open. Creation additionally reserves D cardinality, a fixed-bank insertion slot, the complete child extent and affected-parent policy before those effects. Parent descriptors and both possible temporary walk descriptors are stored in that operation through all fallible work. Root verification uses preallocated-name `lstat`; child verification uses descriptor-relative `fstatat`, avoiding a temporary child descriptor. Every temporary walk descriptor and every operation-retirement descriptor receives one observed native close; uncertain closes are never retried using a potentially recycled descriptor number.

Create/remove effects settle their exact child/parent identities, child and parent durability, affected-parent metadata and generation under the same State guard. A recorded excess charges the observed amount and fences the shared owner. It does not prove a pre-effect physical filesystem bound. Unwind or an unresolved error keeps the actual operation/backing and seals the owner. The immutable diagnostic retains the original failing step, `io::ErrorKind` and native errno plus a separate close failure and diagnostic descriptor number. It does not retain an arbitrary heap-backed `io::Error` source chain. A healthy unknown final open absence returns the operational slot only after descriptor and backing retirement.

Explicit reconcile first requires all external owners/cursors to drain. It closes internal operation descriptors, then retains the diagnostic, names, ancestry and prepared backing across every census Pending step, cancellation and failure. A complete accepted candidate retires that backing before reopening admission. Uncertain native close keeps the slot and diagnosis fenced and requires process restart. The normal successful removal also destroys all concrete pending backing before returning owner/cardinality/extent credit. Private Arc control backing is deallocated before transferring a sole removal owner, with no escaped Weak handle.
